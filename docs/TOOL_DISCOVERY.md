# 工具探索與常用收藏

本機實作：2026-09-30；正式發布：2026-10-01 00:05:31（Asia/Taipei），來源 `09a3150235e8d8514b39d50d3b2cfae677cef1ca`。已提交、推送及部署；主機位置及回復資訊見 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 驗收條件

1. 首頁呈現常用與五個任務入口，完整二十工具移至目錄；每個工具都可經任務入口找到，原工具／分類網址及舊 hash／預填連結仍有效。
2. 搜尋跨任務、分類與收藏篩選，支援常見同義詞及多個關鍵字；收藏只在使用者點星號時保存工具 ID，重整／切換頁面後可使用，不能包含文件資料。
3. 真實瀏覽器確認窄螢幕、收藏錯誤與跨分頁、草稿保留及輸出；靜態 HTML／sitemap／metadata／JSON-LD 與可閱讀內容一致。

## 導覽與維護方式

首頁順序是搜尋、我的常用、依事情找工具及完整目錄入口。主導覽只有「依事情找工具」與「全部工具」；原本四類保留為目錄篩選及既有網址。常用預設顯示最多六個，超過時可展開，以免收藏再次把首頁拉長。總覽、目錄及任務頁下方的說明使用原生 details 收合；停用 JavaScript 仍能展開閱讀及點擊連結。個別工具的用途說明保持展開。

| 任務入口       | 路徑                        | 定位                         |
| -------------- | --------------------------- | ---------------------------- |
| 報價與接案     | `/invoice/task/quoting/`    | 工時、成本、報價、稅額及交期 |
| 請款與收款     | `/invoice/task/payments/`   | 文件、分期、實收及收據       |
| 採購與交付     | `/invoice/task/purchasing/` | 比價、採購、交付、驗收及器材 |
| 費用與報帳     | `/invoice/task/expenses/`   | 報支、分攤、工時與金額       |
| 日期與資料查詢 | `/invoice/task/reference/`  | 日期、工作天、公司及公開資料 |

任務集合允許同一工具重複出現，但每個工具仍只有一份實作與 canonical URL。集合是導覽，不代表自動執行全部步驟。完整目錄為 `/invoice/directory/`，這六個新頁加上原二十五頁，共三十一個 HTML。

後續新增功能時：

- 先判斷它是否有獨立任務、輸入及結果；既有工具的模式宜放回原工具。
- 在 `catalog.ts` 維護穩定工具 ID、主要類型及適合的任務集合。每個工具至少出現在一個集合，集合內不得重複；增加工具不自動增加頂層選單。
- 在 `discovery.ts` 補使用者會說的別名，在 SEO `content.ts` 補用途、步驟、FAQ；同步更新有意鎖定目前數量的路由／產物檢查。
- 搜尋是 NFKC、小寫、空白分詞後的 AND 包含比對，包含「催款→收款進度」「報帳→費用報支」等別名；結果維持目錄順序，沒有遠端 AI 搜尋或模糊拼字排名。
- 新增頁面／更換集合不搬動既有工具網址。發布清單必須依實際產物重建，不能使用前版的固定三十一檔白名單；本輪公開產物為三十七檔。

## 收藏保存邊界

Storage key 為 `invoice-helper:tool-favorites:v1`，內容僅 `{"version":1,"favorites":["quote"]}`。首次訪問及一般導覽不寫入。星號是工具連結旁的獨立按鈕，具可讀名稱、按下狀態與 44px 操作範圍；各工具頁也可直接加入常用。

合法舊資料中的未知工具 ID 可忽略；無效 JSON／schema 原文保留，不自動覆寫。瀏覽器拒絕儲存或配額不足時，保留本頁選擇並明示無法保存，重新整理可能消失。收藏沒有跨裝置／帳號同步；清除網站資料後可能消失。

其他分頁的 storage event 會更新名單。每次使用者點擊前重讀最新名單，只套入明確選擇；尚未寫入的本頁變更亦會保留。localStorage 沒有跨分頁原子交易，完全同時的寫入仍可能由最後寫入者覆蓋；不宣稱解決所有併發情境。

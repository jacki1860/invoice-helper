## 新工具範圍與驗收

工作坊、內訓與活動主持人貼上名單，指定組數，產生可直接分享的完整分組結果。這是參與者分派流程，與既有清單整理、雙清單核對及議程時間計算用途不同。需求價值為產品工作情境推論，沒有可取得的真實使用者回饋。資料僅在當次頁面處理，不新增保存、匯入檔案、帳號或外部傳送。

1. 指定組數均有成員；每位參與者恰好出現一次，各組人數差不超過一人；真正複製與 UTF-8 TXT 內容對應畫面完整結果，500 人仍完整輸出。
2. 每行一人、首尾空白移除、空行略過；NFC 後相同的重名阻擋並提示原始行號。2–500 人、2–100 組且組數不超過人數、每名 80 Unicode 碼點、整份 100,000 碼點及 1,000 行（含空白行，末尾換行也算一行）。貼上後若會超過整份上限，整份拒絕、保留原名單並清除舊結果；其他已輸入的非法內容完整保留且阻擋分組。同名者需自行補識別。
3. 桌面 1440px 與 320px 能完成入口→輸入→分組→核對→複製／下載；改輸入使舊結果與提示失效，重抽重新產生完整結果，站內切換保留、重整清空；隨機來源或下載失敗可恢復。

採洗牌後平均分配，使用瀏覽器隨機來源，不保證再次分組一定不同，也不作人員技能／偏好平衡或抽獎公平認證。範例是合成資料。隨機 API 參考 [W3C Web Cryptography](https://www.w3.org/TR/webcrypto/#Crypto-method-getRandomValues)，工具規則與介面自行設計。

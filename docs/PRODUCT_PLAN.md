# 小事務：產品與開發計畫

更新：2026-09-30（Asia/Taipei）。「小事務」為暫定產品名；程式倉庫沿用 `invoice-helper`。

## 定位與目前狀態

服務自由工作者與小公司，提供公開免登入的行政工具，讓使用者完成一次填寫、計算或查詢後即可離開。

## 首版：三個工具

| 工具     | 現有基礎                                       | 本輪本機實作                                                                         |
| -------- | ---------------------------------------------- | ------------------------------------------------------------------------------------ |
| 發票助手 | 表單、統編查抬頭、稅額計算、多品項、預覽與 PNG | 多品項新增／編輯／刪除及刪除復原；載入範例；即時預覽；明確顯示複製、下載與錯誤狀態。 |
| 稅額試算 | 原本嵌於發票表單的含稅／未稅計算               | 獨立工具入口，顯示未稅額、稅額與總額；複製結果；與發票共用計算核心。                 |
| 公司查詢 | 既有第三方統編查詢                             | 查詢狀態、名稱結果、複製及帶入發票；區分格式錯誤、查無資料與服務失敗。               |

本輪不加入報價單、帳號、雲端帳本、金流、OCR、薪資／扣繳、報稅或電子發票平台串接。PNG 是填寫輔助預覽，下載不等於完成電子發票開立。

## 介面與互動

- 主畫面使用橫向導覽：「發票助手／稅額試算／公司查詢」。桌面版以編輯區搭配文件預覽；手機版提供「填寫／預覽」切換。
- 視覺沿用已確認設計稿的紙張感、清楚字級與橘色操作重點，避免裝飾壓過數值與文件內容。
- 品項修改即時反映至預覽與總額；最近一次刪除提供復原；複製與下載顯示成功或失敗；查詢失敗仍可手動填寫。
- 所有操作具可見鍵盤焦點與欄位標籤；錯誤不用顏色單獨表達；動畫遵循 `prefers-reduced-motion`。
- 預覽、計算摘要、剪貼簿與 PNG 共用資料與計算結果，不各自重算金額。

## 計算與資料邊界

首版以新臺幣和現有一般／零稅率／免稅模式為範圍，不判定使用者適用哪種稅制。修復目標是輸入與輸出一致，並使已支援算式可重現、可測試。

含稅模式必須保留使用者輸入的總額；保留計算精度至稅額取整，避免把顯示用的已取整未稅額重新加稅。已知案例「含稅 10 元 × 1 件，加入品項後變 11 元」必須成為 regression。官方計算依據與適用邊界列於文末；多列尾差分配是需要明確記錄與測試的產品規則，不能包裝為已獲官方認證。

資料策略：

- 首版表單只存在記憶體，不自動保存商業資料。重新整理或關閉頁面不保留當次修改，介面已說明；若網址帶有預填參數，重新整理會再次載入那些參數。
- 計算、複製與 PNG 產生在本機瀏覽器完成；不為這些操作上傳完整交易內容。
- 公司查詢沿用 `company.g0v.ronny.tw`，會將統編傳給第三方；結果如實標示來源並提供官方核對入口，不宣稱所有操作完全離線。
- 保留既有 URL 預填相容性並檢查輸入；不主動把新填寫的完整交易內容寫入網址。網址預填不作為私密資料保存機制。
- 後續若加入本機保存，必須由使用者主動開啟，提供保存狀態與清除功能；不得承諾跨裝置同步或永久備份。

## 階段依賴與驗收

| 階段              | 依賴                       | 可檢查的交付與驗收                                                                                                                  |
| ----------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 0. 來源與基礎     | 無                         | 上游 SHA、合併父提交、備份分支、獨立倉庫與授權紀錄可核對；保留自己的多品項功能。                                                    |
| 1. 計算與建置修復 | 階段 0                     | build、typecheck、lint 及適當測試實際通過；含稅 10 元案例不變 11 元；覆蓋多品項、模式切換、零／免稅與無效數值。                     |
| 2. 三工具新版     | 共用計算核心與已確認設計稿 | 桌面及手機實跑新增／編輯／刪除復原、範例、查詢與失敗處理、複製、PNG；核對畫面及輸出金額一致，長品名與日期不破版，減少動態設定有效。 |
| 3. 對外版本       | 階段 1、2 驗收             | 決定正式名稱與部署目標，檢查公開網址、正式環境查詢與下載；另行記錄部署結果。目前尚未部署。                                          |
| 4. 行政擴充       | 首版穩定與使用回饋         | 先做報價單：客戶／公司資料、品項、有效日期、付款條件與列印；再評估本機草稿／範本。帳號與雲端保存另訂範圍。                          |

本機三工具與本輪程式、瀏覽器及 PNG 驗證已完成，詳見[驗證紀錄](VERIFICATION.md)；正式上線驗收與使用者美術驗收尚未進行。工時待範圍與驗收結果明確後估算，不在此承諾。

## 官方參考與查證範圍

以下來源查證於 2026-09-30；引用是計算與產品邊界的依據，不代表本網站已完成全部稅務或法規合規驗證。

- [營業稅電子資料申報繳稅作業要點](https://law-out.mof.gov.tw/LawContent.aspx?id=GL009478&media=print)：第 20 點第 15 款列出含稅定價拆分與稅額四捨五入公式。營業人買受人公式沒有要求先將反算銷售額取整再計稅；非營業人的當期彙總公式不直接視為逐品項分配規則。
- [加值型及非加值型營業稅法](https://law-out.mof.gov.tw/LawContent.aspx?id=FL006082&media=print)：第 14 條規定銷項稅額不足一元的四捨五入原則。目前未查到直接規定本產品多列預覽尾差分配的官方條文。
- [電子發票實施作業要點](https://law-out.mof.gov.tw/LawContent.aspx?id=FL041411&media=print)：現行頁面修正日為 115 年 4 月 22 日，包含系統檢測、字軌及傳輸要求；現有預覽圖片能力不等同該開立流程。
- [經濟部商工登記公示資料查詢](https://findbiz.nat.gov.tw/)及[商工行政資料開放平臺](https://data.gcis.nat.gov.tw/od/datacategory)：前者供官方核對；未來若改接官方 API，須另行確認適用資料種類與介接限制。

# 成本利潤與廠商比較：公式、取整與交接

核對日期：2026-09-30。這兩個工具沿用專案既有版型與計算核心，未複製第三方產品設計。

## 驗收條件

1. 利潤工具以整數分運算，明確區分毛利率與成本加成率；零分母、非法輸入、上限與目標反推均有測試。
2. 比較工具支援 1–20 個共同品項、2–5 家廠商、含稅／未稅及三種稅別；非法廠商不列最低價，移交採購含稅總額守恆。
3. UI 有範例確認、結果文字／列印／PNG、session 說明及明確 handoff。工時取代／追加須確認；報價 handoff 不含內部成本。

## 第一手來源

- [BDC：Gross profit margin](https://www.bdc.ca/en/articles-tools/entrepreneur-toolkit/templates-business-guides/glossary/gross-profit-margin-ratio)：毛利率是毛利除以淨銷售額；毛利來自收入扣除直接成本。僅用此公式，不採用該頁產業利潤區間當建議。
- [BDC：How to set the right price for your products or services](https://www.bdc.ca/en/articles-tools/marketing-sales-export/marketing/steps-setting-right-price-your-products-services)：加成率使用成本作分母，與以收入為分母的毛利率不同。
- [財政部：營業稅電子資料申報繳稅作業要點](https://law-out.mof.gov.tw/LawContent.aspx?id=GL009478&media=print)：銷項稅額按規定四捨五入。台灣金額與稅額計算直接呼叫現有 `calculateInvoice`，本功能沒有另建稅法引擎。

## 利潤工具的計算約定

所有成本與售價都為未稅新臺幣，輸入最多兩位小數。逐列成本解析成 BigInt 整數分，合計上限 999,999,999 元；不接受負成本、負售價與第三位小數。

- 毛利＝售價－成本。
- 毛利率＝毛利／售價；成本加成率＝毛利／成本。顯示百分比四捨五入至小數點後兩位，負毛利保留負號。分母為零回傳 `null`，UI 顯示「未定義」。
- 有成本但售價零屬無效輸入；成本與售價同為零是合法空效益試算，兩項比率皆未定義。零成本且正售價的毛利率為 100%，加成率未定義。
- 目標毛利率支援 0–99.99%，精度為 0.01%；售價＝成本／(1−目標毛利率)，無條件進位至一分，使實際毛利率不低於目標。此為由上式推導的產品取整約定，非稅法要求。零成本搭配正目標毛利率無法唯一得到符合該比率的正售價，予以拒絕。
- 此為輸入成本範圍內的專案試算，不自動估算未列入的營運費用、所得稅或法定工資。
- 送往報價單只送專案名稱與一列未稅售價，數量 1，未送成本明細、成本合計、毛利或內部備註。報價沿用既有逐列整元取整，因此 UI 在按鈕前顯示實際整元未稅額、含稅額及按整元額重算的毛利率；不宣稱與分精度試算完全等值。

## 比較工具的計算約定

共同品項數量限制為 1–9,999 的整數。每家可獨立選擇含稅／未稅單價與應稅 5%、零稅率、免稅。運費明確標示含稅，沿用該廠商稅別，免運須填 0。

1. 商品先用 `calculateInvoice` 按該家的輸入模式計算。沿用其逐列四捨五入到整元、整張稅額取整與總額限制。
2. 運費用同一函式以數量 1、含稅輸入取整，絕不再對運費加稅。
3. 比較基準是商品含稅總額加運費含稅額，屬現金總支出比較；不推定進項稅額可否扣抵。合併後再以含稅整張模式分拆未稅額與稅額，這與商品、運費分開計稅可能有整元尾差，含稅總支出不變。
4. 無效廠商的總額與價差均為 `null`，不以 0 加入最低價。合法廠商按最低有效含稅總支出計算差額，同價可並列。程式不預選供應商。

## 採購 handoff 總額守恆

固定兩位小數的含稅單價，無法代表所有數量下的整元列金額。例如 9,999 件、原未稅單價 0.01 元會得到商品未稅 100 元、稅 5 元；直接把 105／9,999 四捨五入至單價 0.01 元，將只剩商品含稅 100 元。

因此帶入採購前需明確確認批次轉換：每個商品列以數量 1、整元含稅批次總額建立，名稱寫「原品名（原數量 X；批次）」。商品原為未稅輸入時，以已算出的整張稅額，按各列未稅額比例與最大餘數分配；同餘數依原列順序分配。這是為保全含稅額所作的顯示分配，不另算一次稅。

原品名、原數量、原單價（補足兩位小數）、原單價含稅方式與稅別保存在採購備註；不截斷。含稅運費為獨立品項，即使免運也列出 0。最後重新用 `calculateInvoice` 計算批次列＋運費列，確認總額等於比較結果才允許移交。交期、保固、付款條件與聯絡資料一併帶入；收件採購單仍由使用者補齊自己的採購方資料。

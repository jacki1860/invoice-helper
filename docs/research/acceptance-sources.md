# 驗收／結案確認單：來源與設計範圍

核對日期：2026-09-30。

- 官方來源：[行政院公共工程委員會「45.驗收紀錄」](https://www.pcc.gov.tw/content/index?eid=9853&lang=1&type=C)，位於政府採購的招標相關文件及表格分類，頁面發布日期為 2024-10-14。頁面提供 DOC、ODT、PDF 附件。
- 已讀取官方 [驗收紀錄 PDF](https://www.pcc.gov.tw/downloadFile?fpath=YXJ0aWNsZS8xNzM1MTI5MjM0MzE4LnBkZg%3D%3D&sname=%E9%A9%97%E6%94%B6%E7%B4%80%E9%8C%84.pdf)：內容包含案件與標的數量、日期、驗收經過與結果、改善期限及簽章等欄位；文件末尾說明格式供參考，使用機關可按需求調整。這是政府採購情境的參考表，不能據此宣稱其全部欄位或流程對所有民間合作強制適用。
- 本工具只參考日期、交付項目、檢查結果、改善說明與雙方確認等通用概念，欄位、狀態、文案及版面自行設計，延用本專案紙感文件樣式，不複製競品程式、版面或素材，也不宣稱是工程會核定格式。
- 新增或帶入的項目一律為待驗收，驗收日期須由使用者填寫。逐項可選待驗收、通過或待改善；待改善必須填說明。整體結果依項目狀態計算，載入報價或送貨資料不會自動視為通過。
- 文件輸出保留雙方簽章空白，結果由使用者記錄並由雙方確認；工具不驗證簽章、契約履行或收款事實，也不取代政府採購程序、雙方契約及其約定的驗收標準。
- 原報價的金額僅保留供後續請款，驗收文件不列價格。須資料有效、全部項目通過，且品名／數量與有效來源價格逐項對應，才可帶入請款；品項改動、價格無效或來源未附價格時，提示手動整理，不將未知價格補成零元。
- 帶入新的請款單會清空新請款編號，付款期限由請款單另填；原文件編號保留於說明供核對。驗收通過與轉入請款均不表示款項已收。

本紀錄用於說明來源、實作選擇與適用邊界，不構成個案法律合規認證。核對時網頁擷取工具回報逾時，改由官方網址直接 HTTP 下載 HTML 與 PDF 成功，再以 PDF 文字解析核對上述欄位與參考性說明。

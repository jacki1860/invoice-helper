## 真實瀏覽器操作

主要以 Codex 內建瀏覽器操作，並以 Chrome 交叉核對下載與剪貼簿。測試使用公開公司資料及人造範例。

| 情境           | 實際結果                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 空白表單       | 未填妥時無法下載或複製；零金額與空白欄位分開驗證。                                                |
| 範例           | 兩品項得到銷售額 11,000、稅額 550、總計 11,550。                                                  |

| 範例覆蓋       | 可取消並保留原內容，確認後才取代表單。                                                            |
| 防呆           | 數量 1.5 顯示錯誤並停用匯出；日期清空立即顯示錯誤，恢復有效日期後可匯出。                         |

桌面、手機預覽、手機填寫頁各取得 **1360 × 1634 PNG**；手機填寫頁按下載後切到另一工具仍完成匯出。圖片包含完整品項、數字、日期、中文大寫及「填寫參考・非電子發票」。[匯出樣本](design/export-sample.png)保留桌面範例。

獨立審查指出的「非同步匯出讀到後續修改」及「手機預覽訊息被隱藏」均已修正並復核。匯出在任何 await 前建立獨立 DOM 快照，結束時清除；手機預覽具有自己的操作狀態。

## 設計對照紀錄

概念：[desk-concept.png](design/desk-concept.png)。實作以瀏覽器 screenshot API 擷取，桌面採概念原尺寸 **1505 × 1045**，另檢查 390／320px 與目前內建瀏覽器尺寸。最終透過 `view_image` 同時檢視概念與[桌面實作](design/desktop-preview.png)，並另檢查[手機填寫](design/mobile-editor.png)、[手機預覽](design/mobile-preview.png)及實際 PNG。

| 比較點     | 概念證據                                         | 實作證據與處理                                                                             |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| 整體布局   | 72px 頂列、左側編輯、右側紙張                    | 保留全幅工具、54／46 左右比例、細線分區；沒有另加行銷首頁或卡片格。                        |
| 文字與順序 | 三工具導覽、01 基本資料、02 品項明細、下載／複製 | 名稱、順序、主要文案一致；首屏文字增減逐項核對。新增驗證／狀態／資料說明屬下列必要差異。   |

已依核准概念完成忠實對照驗證，未發現阻擋使用的視覺偏差。這是本輪實作檢查，最終美術接受度仍由使用者判定。

有意保留的差異：初次開啟不預填交易範例；輸入價格不插入千分逗號，以保留小數編輯；補上驗證、覆蓋確認、復原與結果訊息；說明表單不持久保存及第三方查詢；中文大寫修正生成圖誤字；紙內保留非電子發票標示；窄螢幕重排與多品項可延長文件。這些差異已列於[設計規格](design/DESIGN.md)。

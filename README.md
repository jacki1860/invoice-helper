# 小事務 · everyday admin

公開免登入的行政工具，服務自由工作者與小公司。以暖白紙張、墨黑文字與橘色操作組成工作桌，打開即可製作文件、試算或查詢。

「小事務」是暫定產品名，倉庫沿用 `invoice-helper`。[公司網站](https://www.ctrls.com.tw/invoice/)提供二十個公開工具及共用聯絡頁尾。最新發布狀態與回復資訊見[部署紀錄](docs/DEPLOYMENT.md)，各版本的測試、瀏覽器與輸出證據見[驗證紀錄](docs/VERIFICATION.md)。

頁首右上角的 [Buy me a coffee](https://www.buymeacoffee.com/jacki1860) 支持連結使用網站橘色與白字，手機版與品牌同列。

總覽、四類頁面與各工具的共用頁尾提供「聯絡開發者」及「許願新功能」，以 `mailto:` 連至 `jacki1860@gmail.com`，分別預填不同主旨與內容提示。本站不直接寄出郵件；實際寄送由使用者在郵件應用程式確認。頁尾不列入文件列印。

工具銜接由使用者按鈕發起，接收端再確認套用：工時 → 成本、成本售價 → 報價、報價／送貨 → 驗收、驗收 → 請款、比價 → 採購。驗收帶入後預設待驗收，日期留待確認；所有項目通過且仍對應來源價格才能轉成請款。未顯示價格的送貨單不會把隱藏單價帶入驗收。成本明細不會自動出現在客戶報價。

報支與借還的 JSON 是當份有效文件備份，匯入須通過版本、結構、欄位及業務規則驗證，再確認取代當前內容。兩工具不自動保存或上傳資料；借還的累計已還數量與最近歸還日不構成逐次歸還歷史。

首頁提供工具搜尋與四類導覽，保留 `#invoice`、`#tax`、`#company` 舊入口。文件工具可載入範例；已有內容時先確認是否取代。發票助手桌面並排編輯與預覽，手機可切換「填寫／預覽」；報價／請款單在手機依序顯示編輯與預覽。

報價與請款單提供獨立的電話號碼、信箱選填欄位，另可新增多筆「欄位名稱＋內容」，例如地址、聯絡人或專案代號。自訂內容可換行、可移除，預覽、複製文字、PNG 與列印共用同一份內容；全空白欄位略過，填寫一半時提示補齊或清空。

報價與請款單可上傳、更換及移除 Logo，支援 5 MB 以內的 PNG、JPG、WebP。Logo 保持比例，顯示於抬頭右側並帶入 PNG 與列印／PDF；透明 PNG 可保留透明背景。圖片只在瀏覽器處理，重新整理後不保留；複製文字不包含圖片或圖檔名稱。

請款單可帶入應收案件或收據，接收端會先讓使用者確認套用。從請款單帶入收據時，實際收款日期與方式留白；從收款紀錄建立收據時，只帶入選定的單筆實收。收據不是統一發票，是否涉及印花稅取決於憑證性質與免稅規定，工具不判定免稅資格或代繳稅款。來源與獨立設計紀錄見[行政工具來源](docs/research/admin-tools-sources.md)。

含稅／未稅切換會以目前單價重新計算，**不會自動換算或改寫單價**。發票預覽與文件輸出**非正式電子發票**，下載不等於完成開立、傳輸或申報。工時費用不判斷勞動法令或加班費；勞健保查表不判定納保身分，也不是保費試算。

## 官方資料與更新

勞健保、法規與行事曆使用隨版本發布的資料快照，沒有背景排程或即時同步。畫面保留核對日、生效日或年度、來源連結；法規公告日、修正日與生效日分開呈現。

- 勞健保：已核對 2026-01-01 生效版本；勞保 97 列、四種身分，健保 58 級。未推算 2027 年級距。詳見[級距來源](docs/research/insurance-sources.md)。
- 法規：2026-09-30 核對 14 部核心法規及三個官方首頁的部分公告；全國法規整編截止日為 2026-09-18。本站不提供完整法規全文搜尋，另連至官方搜尋。詳見[法規來源](docs/research/law-sources.md)。
- 日曆：兩年各 365 日；全年 ICS 分別 22／24 筆節日與政府補假事件。政府辦公日曆不直接代表所有勞工的排班與補假。詳見[日曆來源](docs/research/calendar-sources.md)。

維護者使用 Node 24、系統 `curl` 與已安裝的專案依賴人工更新，再檢查 diff、測試及建置：

```bash
node scripts/refresh-insurance.mjs --check
node scripts/refresh-insurance.mjs --write
node scripts/refresh-laws.mjs
node scripts/refresh-calendar.mjs
npx oxfmt src/data/insurance.ts src/data/laws.ts src/data/calendar.ts
```

勞健保 `--check` 只核對已登錄版本；`--write` 通過檢查後才寫入。法規與日曆命令成功時會更新快照；來源格式或資料驗證失敗時保留原檔。新年度或新級距須先核對官方公告並更新來源登錄，不能把執行成功視為自動涵蓋所有未來版本。更新不會自動發布網站。

## 資料如何處理

- 一般文件、表單與查詢結果只留在本次頁面的記憶體；切換工具仍可保留，重新整理或關閉頁面後不保留當次修改。沒有帳號或雲端同步。
- 收款進度預設也只留在記憶體；主動勾選「在這個瀏覽器保存收款紀錄」後，已儲存的案件與實收會寫入 localStorage，未送出的欄位不保存。可下載 JSON 備份、驗證及確認後取代匯入，或確認停用並清除本站此工具資料；瀏覽器清除網站資料仍會使紀錄遺失。
- 收款本機資料損壞、寫入失敗或偵測到另一分頁變更時會暫停保存並保留畫面資料，提供備份與復原。操作前的版本比對能攔截已發生的變更，但 localStorage 不提供跨分頁交易，請避免同時編輯同一份帳本。
- 計算、PNG／ICS 產生及複製明細在本機瀏覽器執行，不為這些操作上傳文件內容。列印／另存 PDF 使用瀏覽器列印功能。
- 公司查詢會將 **8 位數統編**傳至第三方[台灣公司資料](https://company.g0v.ronny.tw/)，不傳送發票品項或金額。查詢結果可至[經濟部商工登記公示資料查詢](https://findbiz.nat.gov.tw/)核對。
- 點擊「全國法規搜尋」會將輸入的關鍵字帶到官方網站；點擊來源連結會開啟對應外部網站。本站核心法規篩選與快照查表在本機進行。
- 相容既有 URL 預填參數：`uniformNumber`、`amount`、`itemName`、`date`。網址中的資料可能出現在歷史紀錄或分享內容中；不要把私密交易內容當成網址保存。重新整理帶有預填參數的網址，會再次載入那些參數。

一般文件的本機草稿與範本、帳號及雲端服務屬後續評估，詳見[產品計畫](docs/PRODUCT_PLAN.md)。

## 本機開發

使用 **Node.js 24** 與 npm；版本記錄於 `.nvmrc`。使用 nvm 時可先執行 `nvm install`、`nvm use`。

```bash
npm ci
npm run dev
```

開啟終端顯示的本機網址。工具鏈為 React 19、TypeScript 7、Vite 8、Tailwind CSS 4；Cloudflare Vite plugin 與 Wrangler 用於現有執行環境設定。

## 檢查與建置

```bash
npm run lint
npm run format:check
npm test
npm run build
npm run build:company
```

`build` 先執行 TypeScript 檢查，再產生 Vite 建置產物。測試涵蓋文件與稅額計算、分攤、工時、成本與利潤、廠商比較、驗收交接、報支與借還備份、日期／中文金額、收據／採購／送貨、收款備份與儲存衝突、工作天、公司查詢、級距、法規及 ICS；瀏覽器操作與實際匯出外觀另行驗證。

| 指令                   | 用途                                |
| ---------------------- | ----------------------------------- |
| `npm run format`       | 使用 oxfmt 格式化檔案，會修改檔案。 |
| `npm run format:check` | 檢查格式，不修改檔案。              |
| `npm run preview`      | 重新建置並啟動本機預覽。            |

公司站點使用 `npm run build:company`，資源路徑為 `/invoice/`，只發布 `dist/client/` 的內容。`npm run deploy` 仍是原有 Cloudflare 部署指令，不用於公司 SSH 主機。
